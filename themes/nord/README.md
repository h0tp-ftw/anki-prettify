# Nord × Catppuccin

This is the single maintained theme in the h0tp-ftw fork of Anki Prettify. It keeps the Nord package name and stable note-type IDs while combining Nord neutrals with Catppuccin-inspired Latte and Mocha accents.

![Cursor-guided Anki Prettify preview and editor walkthrough](../../res/gifs/preview-editor-cursor-v2-crisp.gif)

The walkthrough above is captured from this fork's real preview and editor. Try the same controls in the [hosted preview and live editor](https://h0tp-ftw.github.io/anki-prettify/).

## Included note types

- [Basic](notetypes/prettify-nord-basic.apkg)
- [Basic + Reverse](notetypes/prettify-nord-basic_reverse.apkg)
- [Cloze](notetypes/prettify-nord-cloze.apkg)
- [Complete Nord bundle](prettify-nord.apkg)

## Highlights

- Responsive light and night modes
- Rubik-first typography
- Animated deck breadcrumbs and nested tag tooltips
- Progressive image zoom and full-screen viewing
- Image contrast toggle
- Persistent-webview cleanup for repeated Anki reviews

See the [project README](../../README.md) for installation, font setup, customization, and development instructions.
